# Credits — UI / input / PWA module (`src/input/**`, `src/ui/**`, `public/icons/**`, `public/sw.js`, `public/manifest.webmanifest`)

No third-party assets were downloaded for this module. Everything is made in code:

| Asset | How it is made |
|---|---|
| F-35A top-view silhouette (logo, mission cards, hangar store diagrams, PWA icons) | Hand-traced planform coordinates in `src/ui/art/planform.ts`, rendered as SVG paths |
| "F35-A" logo / emblem (reticle, sweep, brackets) | Inline SVG, generated by `src/ui/art/logo.ts`, animated with CSS |
| Icons (time of day, weather, modes, menu glyphs) | Hand-drawn 24×24 SVG paths in `src/ui/art/icons.ts` |
| Animated tactical-map menu background, briefing intel map | Canvas 2D (`src/ui/art/menuBackground.ts`, `src/ui/screens/intelMap.ts`). The Auckland coastline polygons are read from the WORLD module's hand-traced map data (`src/world/terrain/theaters/aucklandMap.ts`) |
| Mission-card skies and the Auckland skyline (Rangitoto, CBD, Sky Tower) | CSS gradients and an inline SVG data URI in `src/ui/styles/screens.css` |
| PWA icons `public/icons/icon-{180,192,512}.png`, `icon-maskable-512.png`, `icon.svg` | Rendered from SVG with headless Chromium by `tools/gen-icons.mjs` (playwright-core) |
| Touch controls (stick, throttle, buttons) | DOM + CSS (`src/input/touch/*`) |

Fonts: the menus use the platform system font stack. Numeric read-outs use the HUD module's "B612 HMD" face when it has
loaded (see `docs/credits/hud.md`, SIL OFL 1.1) and fall back to the system monospace font otherwise.

Libraries used at build/test time only: playwright-core (Apache-2.0) for icon rendering and screenshots.
